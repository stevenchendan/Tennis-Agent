# 教案库交付里程碑

本轮目标：将已完成的120课按可独立审阅、验证、回退的边界交付。课程内容完成不等于已合并；只有 GitHub 确认合并后才更新交付状态。

## 工作约定

- 每个里程碑开始前，从最新 `origin/main` 创建新的 `codex/` 分支。
- 一个 PR 只解决一个清晰问题；无关修改保持未暂存，不使用 `git add .`。
- 人工编写内容按水平分批审阅。生成的 HTML、JSON 与 PDF 单独标明，不用压缩代码隐藏真实改动规模。
- PR 描述包含问题与结果、范围、验证方法和结果、已知限制及回退方式。
- 提交前检查暂存差异；PR 创建后检查文件清单、CI、审阅状态、冲突与最新提交。
- 通过适用验证并处理阻塞问题后合并；不绕过分支保护、失败检查或必需审阅，不强制推送主分支。
- 合并后同步主分支，再开始下一分支。用户已授权本轮自行创建、提交、推送、创建PR与合并；不重复请求常规确认。
- 外部权限或必需人工审阅阻塞时保留分支和准确状态，说明具体原因；不能把本地提交或自动合并排队标为已合并。

## 生成物与审阅重点

- `frontend/content/lessons/*.txt`：人工编写的课程；每行一课，字段由 `|` 分隔，按目标、练习A/B、游戏、口令、验收、降阶、进阶及图型审阅。
- `frontend/scripts/coaching/`：可维护的实现与验证；不当作生成物隐藏。
- `frontend/public/coaching/`、`output/`：生成的发布产物；核对生成来源和一致性，避免手工修改后与源文件漂移。
- 课程分级与验收阈值是教学建议；未经过真实教练课堂验证，不声称官方评级或保证升级。
